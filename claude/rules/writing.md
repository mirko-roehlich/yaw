# Writing

Write text for humans in the pragmatic mode of the `simple-english` skill: issues,
pull requests, comments, review findings, reports, and commit messages. Read its
`SKILL.md` and the files in its `references/` folder with the Read tool before the
first text of a session.

Do not apply the skill to code, code comments, commands, or quoted output.

Do not reference other products, prototypes, or the origin of an idea. A reason
stands on its own.
